# 青枫 UI 字体

本目录保存原始完整字体，没有使用美术预览网页的字形子集，也没有修改字体轮廓或字体内部名称。

| 文件 | 原始字体 | 用途 |
| --- | --- | --- |
| Round-Semibold.otf | Chiron GoRound TC SemiBold / ChironGoRoundTC-600SB.otf | 界面标题、姓名签、短按钮 |
| Round-Medium.otf | Chiron GoRound TC Medium / ChironGoRoundTC-500M.otf | 选项、设置项目、数字 |
| SourceHanSansSC-Heavy.otf | Source Han Sans SC Heavy | 主菜单既有字形的完整字体备份；当前主菜单字已包含在 PNG 中 |

正文继续使用游戏根目录已有的 `SourceHanSansLite.ttf`。

所有字体均使用 SIL Open Font License 1.1，完整条款见 [OFL.txt](OFL.txt)。原字体内的版权、作者和许可证元数据保留。字体文件名的更改只用于项目路径，不代表字体家族改名。
