# 校园转绘背景接入

2026-10-26：导入用户已认可的全部90张校园转绘PNG，并在第一章Demo中替换有对应场景的13个背景定义。宿舍、高中回忆教室、带准确社团招牌和人群的青枫摊位保留原图；不改剧情、角色立绘、主视觉或Logo。

## 资源位置

- `game/gui/scene/campus/`：90张2048×1152 PNG，原stem文件名，共约302 MB，使用Git LFS。
- `game/scene_photo/`：既有90张实拍原片，保持不变。
- `game/gui/scene/campus/manifest.json`：来源照片、编号、分类、尺寸、SHA-256与Demo映射。所有路径相对仓库，无本机盘符或密钥。
- `game/settings.rpy`：原image名称接入新路径，使用`Transform(..., xysize=(1920, 1080))`完整显示16:9画面。移除该文件中原先重复一遍的同名背景定义，人物定义不变。
- `game/qingfeng_ui.rpy`、`game/ova.rpy`：小说阅读底图改为共用`room1`，避免绕过新背景定义。既有UI测试场景也改为共用image名称，日间示例使用`block`。
