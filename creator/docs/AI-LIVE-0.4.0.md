# AI 侧栏 0.4.0

## 使用

- 输入消息后按 Enter；Shift+Enter 换行，中文输入法选字不发送。
- 底部圆形按钮空闲时发送，运行时停止当前对话。运行中 Enter 将消息排队，点击“引导”可在下一执行步加入要求；已经执行的工具不会因此撤销。
- 顶部加号新建对话，历史中可搜索、重命名、置顶、归档和恢复。同一项目的不同对话独立运行，切换对话不会停止其他对话。
- 代码、三轨、虚拟素材详情中的“添加到 AI”带入当前选择。输入框的加号或 @ 可选择文件、场景和素材，发送前可移除标签。
- 普通 AI 修改直接进入当前编辑稿，并保存涉及文件。它能读取未保存内容；若涉及该文件原有的手工输入，也会一并保留并保存。其他文件不随之保存。
- “查看文件修改”在中央打开 Monaco 差异页，可逐文件保留、撤销或撤销整批修改。检测到新增声明及引用的文件会联动处理。遇到后续编辑先合并，不覆盖新输入。
- 手工修改仍遵守 Ctrl+S／“自动保存手工修改”设置；Hot Exit 持续保护未保存草稿。

## 权限

“请求批准”由用户审核需要额外权限的操作；“帮我批准”使用独立模型上下文审核，会产生额外用量。普通工程源码编辑无需逐次批准。拒绝、超时或证据不足都不执行，允许人工处理。授权绑定具体命令、目录和内容版本。

两种方式都不允许更改项目外文件、凭据或实际素材。通用 PowerShell 命令只在内部执行快照运行，文本结果经过统一源码事务回写。Windows 隔离报告为 partial，不代表完整读取、网络或进程隔离；不可用时阻止执行。

## 数据与兼容

锁定 DSH 提交及 Node／PowerShell 版本不变。原生文件工具通过 IDE ctx.fs 适配器访问编辑稿，复用 DSH 的观察策略；多个工作进程的提交由 IDE 统一协调。版本失效时必须重新读取。外部文件修改由摘要检查及三方合并处理。

新会话和执行历史在本机应用数据目录按项目分开保存。旧任务副本保留为历史，不自动应用。恢复会话、排队消息和进程中断记录不会自动重跑命令、测试或试玩。API Key 沿用当前本机安全存储，不跨配置目录复制密文。

游戏仍由原 RPY 和已保存的虚拟素材映射运行；发行使用 Ren’Py 启动器“构建发行版”。本版本不提供新的 Word／图片附件入口。
