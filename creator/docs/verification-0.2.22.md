# 0.2.22-no-ai.1 验证记录

日期：2026-10-21。Windows 10 x64，Ren’Py 8.5.3.26051504。

## 本轮修复

- 补回原工程配置入口使用的 Settings2 图标导入，消除渲染时的未定义引用。
- 统一立绘动作编辑中的素材脚本元数据，修复动作设置后更换差分报错。
- 免安装校验改用 .NET SHA-256，避免 PowerShell 模块环境缺少 Get-FileHash 时无法首次启动。
- 新建索引时从 Morinote 已知角色目录补上角色分类；不猜测服饰、表情，也不覆盖已保存的自定义分类。
- 根目录中的图片、音乐文件名也进入缺口登记，对白里的同名文字不作为素材。
- 保留 Electron 标准 user-data-dir 参数，用独立测试配置避免污染用户会话。
