# Morinote IDE 0.3.4：AI 侧栏

## 启动与设置

使用 `creator/启动IDE.cmd` 启动同步清单指定的免安装包。配置好模型和 Key 后，在侧栏输入消息点击“发送”即可对话；“新对话”开启独立上下文。打开 IDE 或侧栏不会启动模型任务；只有主动发送消息或点击连接检查才发出模型请求。未配置 Key 时仍可离线编辑、使用三轨、Voice、虚拟素材库和 Hot Exit。

在顶部点击 **AI → 模型设置**，选择 DeepSeek、OpenAI 或 Anthropic，填写模型名称、端点和自己的 Key。Key 由 Electron safeStorage 加密，沿用 `%APPDATA%/Morinote-IDE-Offline` 应用目录。模型名和端点可自定义；第三方网关需要支持相应协议。连接检查由同一 DSH SDK 发出一个短请求，会产生少量用量。

加密 Key 只能在其原本的本机配置中使用；不同 user-data-dir 的 Chromium 加密密钥可能不同，不能复制 encryptedKey 密文实现迁移。需要迁移时，在正确的配置上下文中读取并重新加密；不得把明文写入项目或日志。解密失效时侧栏显示“重新配置”，保留原密文和记录，重新输入保存即可恢复；保存时进行本机加密解密校验。

DeepSeek 官方端点使用 `https://api.deepseek.com`，模型填写 `deepseek-flash`，当前对应 DeepSeek V4.1 Flash。官方端点使用 DSH 原生 DeepSeek 适配器，支持该模型的图片输入；自定义网关使用通用适配器，需另行确认能力。Key 不随项目或免安装包分发。

## IDE 专用 Skill

随附 `ai/skills/morinote-ide/SKILL.md`，详细说明在其 `references/`。DSH 挂载官方的 Skill 注册、文件提供方和 `skill` 工具；仅扫描安装包的技能目录，不自动加载用户目录或工程中的其他 Skill。

系统规则要求制作前使用 `skill(name="morinote-ide")`，再按任务调用只读的 `morinote_guide`：

- `architecture`：整个 IDE 的界面与实现分层，原 RPY、索引、编辑稿、副本、审核及保存的关系。
- `tracks`：三轨、文字推进、继承拆分、Voice、立绘实例与内置缩放、动作、并行音频的真实操作参数。
- `systems`：唯一总剧情图、分支与状态、手机和通讯录、OVA、成就、自定义组件及源码边界。
- `assets`：虚拟条目、实际资源和图片标签，缺失需求、临时替代及更换操作。
- `verification`：静态检查、lint、testsuite、试玩截图、终端授权、版本证据和审核恢复。

Skill 与指南读取会出现在执行记录。连接检查不加载 Skill，也不修改项目。恢复旧会话时沿用原对话并使用当前随附规则；重新进入制作任务时应重新读取 Skill。修改 `ai/skills/` 后需重新打包；组装程序同步指南和插件到包外运行目录，确保独立 Node 能读取。该能力不提供修改 IDE 自身 React／Electron 源码的权限。

## 制作与审核

1. 选择场景或台词，在侧栏输入问题或制作要求并点击“发送”。无需先保存；后台自动捕获当前未保存文本、新建／待删除文件、配置草稿和选择上下文，建立受保护的任务副本，不要求用户手工建立任务。
2. AI 查询源码、总流程图和项目素材，再使用与 IDE 相同的源码适配器修改副本。Voice 绑定台词；BGM、环境音及音效仍按原音频系统处理。
3. Agent 可以调用静态分析、素材验证、Ren’Py lint、工程声明的 testsuite、副本片段试玩和截图。没有 testsuite 时返回“未运行”，不冒充通过。结果附内容摘要；内容变化后显示过期。
4. 普通问答直接显示回复；产生修改时显示“审核差异”。查看新增、修改、删除文件及配置；有期间编辑或外部变化时，先合并，再重新审核。
5. “应用到编辑稿”只更新编辑器，一次应用可整体撤销。默认由 Ctrl+S 或现有试玩保存流程写入源码。

任务副本位于项目 `.creator/ai/tasks/`；对话显示记录、DSH 会话和加密凭据位于应用数据目录。任务副本与实际素材使用独立复制；工具没有写入正式工程的通用接口。不要把任务目录作为正式工程打开或提交给版本控制。

同一对话中的后续消息自动续接，沿用该轮记录的服务商和模型，并使用安全存储中当前的 Key；要采用新模型请开启新对话。应用修改后再次发送，后台从最新编辑稿创建下一轮副本，携带有限的历史对话上下文，界面仍保留同一对话记录。恢复本身仅恢复上下文。已登记的执行请求与通用终端调用通过台账去重；结果不明时要求核实，不自动重放命令、测试或试玩。切换项目、取消执行或退出会取消未批准操作并结束所属进程。隐藏侧栏只改变布局。旧配置中的 enabled 字段不再参与判断，已保存的 Key 与会话继续保留。

## 终端与预览

固定检查入口可由 Agent 按需调用。额外的通用终端操作会逐条展示完整 PowerShell 7 命令、工作目录、目的、写入范围和授权有效期；每次都需要批准，不保留跨命令 Shell 状态。拒绝后修改命令或重试需要新的授权。

Windows 使用 DSH 的 ACL 受限令牌后端，写入范围为任务副本及专用临时目录。官方报告为 **partial**：它不提供完整文件读取、网络或进程隔离。后端不可用、启动失败或授权版本过期时阻止执行，不回退到无限制运行。

副本预览是独立 Ren’Py 窗口，使用副本源码和隔离存档。截图由引擎实际产生。文字模型可取得截图位置和结果；视觉分析需要支持图片输入的模型。源码本身可以包含任意 Ren’Py/Python 扩展，应用之前应审核代码差异。

## 自动保存与 Hot Exit

“自动保存源码”是全项目选项，默认关闭。开启后，停止输入一秒安排串行保存，包括手工编辑和已审核应用的 AI 修改；不会自动应用待审核副本。冲突、恢复待处理或写入失败时暂停，界面提供重试。

Hot Exit 继续自动备份草稿；“草稿已备份”和“源码已保存”分别显示。保存期间的新输入仍保持未保存。AI 的新建、修改、删除状态也进入草稿与恢复历史。

游戏发行仍通过 **打开 Ren’Py 启动器 → 构建发行版**。Ren’Py 8.5.3 默认排除点目录；IDE 与 AI 运行时位于制作器目录，凭据不进入游戏。若自行修改了 Ren’Py 打包规则，需继续排除 `.creator` 和制作器目录。

## 运行依赖和源码构建

- DSH SDK／CLI：`0.2.1-rc.3`，固定官方提交 `22ddee3792402c3e70ec5f86a63c3e3e895a2f60`。
- 独立 Node.js：`25.8.2`；PowerShell：`7.6.5`。均包含在免安装包中。
- 模型执行：侧栏 → Electron → 独立 Node 工作进程 → 官方 DSH SDK／CLI → Morinote 工具插件。
- `backend/ai_tools.py` 提供统一工具描述；`ai/plugin/morinote.mjs` 负责 DSH 注册、受限执行和桥接；`electron/ai-manager.cjs` 管理任务、凭据、授权及生命周期。

开发构建先获取固定提交的官方源码并按其 `pnpm-lock.yaml` 安装生产依赖，包含 `@deepseek-ai/dsh-sdk-client...` 与 `@deepseek-ai/dsh-llm-pi-ai...` 的依赖闭包，禁止生命周期脚本。使用 Node 25.8.2 调用：

```powershell
node scripts/build-ai-runtime.cjs <固定提交源码目录> <node.exe> <PowerShell目录> <Node许可证文件>
npm run build
npm run package:dir
```

构建器从同一源码生成 SDK、CLI、插件和 Windows 沙箱入口，使用 Ren’Py 随附 Python 完成二进制复制。专用配置不启用 Typert 网关、浏览器界面、插件市场或多 Agent；没有伪造这些模块的构建产物。构建产物及许可证清单在 `ai-runtime/`，该目录不作为源码提交；免安装 ZIP 包含运行所需内容。
